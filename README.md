TermBoard is for android superuser inspired the legendary Hacker's Keyboard, stripped all the linguistic features and only retain the modifier keys with added clipboard history, emoji picker, split mode, and layers(like qmk/zmk keyboards). No linguistic feature is gonnabe added

this keyboard is designed mainly for terminal or remote desktop interaction from android tablet, this keyboard aimed to take the nice thing from gboard and hackers keyboard and removing all the bloat feature that i personally never use.

trying to be as minimal as possible, built using kotlin.
